# Qobuz Proxy – Home Assistant add-on

Turn **any DLNA/UPnP player** into a fully featured **Qobuz Connect** device,
for example a free moOde audio player on a Raspberry Pi, Volumio, upmpdcli, or
network speakers and receivers. Pick it as playback target in the official
Qobuz app and control play, pause, skip, queue and volume from your phone,
in hi-res quality.

A version of QobuzProxy packaged with Claude Code as a Home Assistant add-on.
Free and open source (MIT).

- Runs on Home Assistant OS / Supervised (amd64 and aarch64, e.g. Raspberry Pi 4/5)
- Web UI to log in to Qobuz and add speakers, no YAML needed
- Auto-detects the best audio quality each speaker supports (up to 24-bit/192 kHz)

See the **Documentation** tab for setup.
