# Changelog

## 1.7.7.1

- Web UI now opens inside Home Assistant (Ingress) and can be shown in the
  sidebar ("Show in sidebar" on the add-on page).

## 1.7.7

- Updated to upstream QobuzProxy 1.7.7.
- New: choose the device icon shown in the Qobuz app per speaker
  (Speaker, Streamer, Soundbar, Headphones, TV, ...) in the web UI.
- Automatic weekly sync with the upstream project.

## 1.7.6

- First Home Assistant add-on release, based on QobuzProxy 1.7.6.
